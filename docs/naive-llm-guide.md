# 裸 LLM 纠错实战指南（推荐的生产路径）

三轮实验（见 `docs/findings.md`）的赢家路径：**不用判别模型，直接让 LLM
改，但必须戴护栏**。本文是可抄作业版。

## 选型

| 项 | 推荐 | 理由 |
|---|---|---|
| LLM | suanli `deepseek-v4-flash-0731-free` | 非推理、稳定交卷（10/10 有效输出）、免费、2-3 秒 |
| 不推荐裸改 | opencode `deepseek-v4.1-flash` | 推理模型，自由发挥时 2/10 空回复（思维链烧光 max_tokens）；它的正确岗位是"受约束回填"（级联里零翻车） |
| 场景例外 | 不能容忍改错（纪要/存证） | 用级联：jev-1.13-free 定位 + 4.1flash 约束回填（`scripts/run_experiment.py` 的 D 路径） |

## Prompt 模板（实验实测，zh）

```
system: 以下是一段语音识别(ASR)的中文转写，可能包含错字。请只纠正明确的错字，
        保持其余内容完全不变，直接输出纠正后的完整文本，不要解释。
user:   <转写文本>
```

英文同构。温度 0。

## 三条护栏（挡住已观测到的翻车模式）

1. **改动量上限**：最多改 2 个字/词，其余原样。实现：对比输出与输入，
   超限 → 不采纳，用原文（或要求重出一次）。
2. **空回复重试**：返回空串/纯空白 → 重试（推理模型必须加这条；顺带
   max_tokens ≥ 3000）。
3. **输出剥壳**：剥首尾引号、代码围栏、任何"好的，纠正后是："前缀，
   再进归一化对比。

## 调用粒度：5 句一批 + 滑窗重叠（推荐离线默认）

```
第1批: [句1 句2 句3 句4 句5]   只允许改句2-句4，句1句5 仅为上下文
第2批: [句4 句5 句6 句7 句8]   只允许改句5-句7
...
```

- prompt 写明："首尾两句仅供理解语境，原样保留，只修改中间句子"
- 重叠 1-2 句：每句都有左右邻居帮判同音字/专名，又避免两批改出两个版本
- 护栏按批算：上限 ≈ 中间句数 × 2 处
- 实时字幕/流式：退回单句粒度（延迟优先，牺牲上下文）

> 诚实标注："批量优于单句"目前是工程推理（上下文有助于中文同音字判别），
> 未实测。单句粒度的实测成绩是 -72%（zh -85%）。验证方法：同 10 句考卷
> A/B 单句 vs 5 句批（manifest 在 `experiments/round1-ci-v4flash/`）。

## 必做的文本归一化（否则指标全是假的）

SenseVoice 输出阿拉伯数字 + 标点，AISHELL/LibriSpeech 标注是文字数字、
无标点——直接对比会制造海量假错字：

- zh：数字→中文数字（`asr_ec.py: arabic_int_to_zh`），去标点/空白，仅留 CJK
- en：数字→英文数字词（`en_int_to_words`），小写、去标点、折叠空白
- 注意年份坑："2005" 转成 "二千零五" vs 标注 "二零零五" 仍有残差（逐位读法
  vs 数值读法），干净语料上会贡献 1-2 个假错误位，统计时心里有数

## 成本与延迟参考（10 句实测）

- 裸改：每句 1 次调用，2-3.5 秒/句（v4-flash，suanli）
- 级联（对照）：每句 3+ 次调用（判别 + choice×N + LLM 兜底），3.8-11 秒/句
- 全链免费额度内：suanli flash 免费 / 硅基流动判别免费 / opencode Go 套餐
  （jev-1.13-free 经用量护栏验证跑完全程 5h 窗口仍 0%）
